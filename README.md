# Finance Tracker

Finance Tracker — мобильное Android-приложение для учета личных финансов.  
Приложение позволяет вести операции по счетам, группировать их, фильтровать ленту и анализировать доходы и расходы.

Backend проекта: [Finance Tracker Backend](https://github.com/freestyl3/Finance_tracker)

## Статус проекта

Проект находится на начальном этапе разработки Android-клиента.
На данный момент реализован/описан backend-функционал и доменная логика, которые будут использоваться при разработке мобильного приложения.

## Основные возможности

- Авторизация и регистрация пользователя
- Учет доходов и расходов
- Управление счетами
- Управление категориями операций
- Группировка операций в цепочки
- Фильтрация операций
- Просмотр финансовой сводки за выбранный месяц
- Просмотр информации о пользователе

## Лента операций

Экран ленты отображает список финансовых операций.

### Возможности экрана

- операции сгруппированы по датам
- отображаются доходы и расходы
- операции могут быть объединены в цепочки
- доступна фильтрация по параметрам
- отображается месячная сводка доходов и расходов

### Цепочки операций

Цепочка — группа связанных операций.

Цепочка:

- раскрывается и показывает входящие в нее операции
- суммирует операции внутри группы
- имеет дату, категорию и описание

Создание цепочки:

1. Пользователь удерживает операцию.
2. Открывается меню создания цепочки.
3. Пользователь выбирает операции нажатием.
4. Операции добавляются в цепочку или удаляются из нее.
5. Пользователь указывает дату, категорию и описание.
6. Пользователь подтверждает или отменяет создание цепочки.

### Фильтрация

Лента поддерживает фильтрацию по:

- диапазону дат
- счетам
- категориям

### Финансовая сводка

На экране отображаются карточки:

- сумма доходов за выбранный месяц
- сумма расходов за выбранный месяц

Месяц определяется по позиции пользователя в ленте.

Основные разделы приложения:

## Счета

Экран счетов отображает карточки пользовательских счетов.

### Карточка счета

Карточка содержит:

- название счета
- текущую сумму

Счета разделены по типам:

- дебетовые
- наличные

### Действия со счетом

При нажатии на счет:

- пользователь переходит в ленту операций
- лента фильтруется по выбранному счету

При удерживании счета открывается диалог, где можно:

- изменить название счета
- архивировать счет

### Дополнительные действия

На экране доступны:

- добавление нового счета
- переход к архивным счетам

Экран архивных счетов аналогичен основному экрану счетов.

## Добавление счета

Экран добавления счета содержит поля:

- название счета
- начальный баланс
- тип счета

## Добавление операции

Экран добавления операции содержит поля:

- тип операции: доход или расход
- сумма
- описание
- дата
- счет
- категория

Описание является необязательным полем.

## Переводы между счетами

Необходимо спроектировать отдельный сценарий для перевода средств между счетами.

Возможные варианты реализации:

- отдельный тип операции `Transfer`
- две связанные операции: расход с одного счета и доход на другой
- отдельная сущность перевода, связанная с операциями

## Категории

Экран категорий отображает список категорий операций.

### Возможности экрана

- переключение между категориями доходов и расходов
- добавление новой категории
- изменение существующей категории
- удаление категории

### Добавление категории

При нажатии на кнопку добавления открывается диалог с вводом названия.

Ограничение:

- нельзя создать две категории с одинаковым названием в рамках одного типа операций

### Изменение категории

При удерживании категории открывается диалог, где можно:

- изменить название категории
- удалить категорию

## Отчеты

Раздел отчетов находится в разработке.

Планируемая функциональность:

- анализ доходов и расходов
- статистика по категориям
- динамика баланса
- сравнение периодов

## Пользователь

Экран пользователя отображает информацию о текущем пользователе.
